# GlowUp — Responsive Skincare Landing Page

## Project Description
GlowUp is a modern, responsive skincare landing page created as part of my Web Development Internship at CodeOrbit Tech.

## Developer
Nabeeha Rahman

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Attractive pink and purple design
- Responsive layout for mobile, tablet, and desktop
- Navigation links
- Skincare product cards
- Interactive buttons
- Developer credit in the footer

## Setup Instructions
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Ensure an internet connection is available for online images, if used.
